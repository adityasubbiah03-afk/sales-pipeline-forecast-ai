# Building the Power BI dashboard (about 45 minutes)

The pipeline already outputs a clean **star schema** in `data/processed/`, so Power BI needs
no transformation work. This guide gives the model, the DAX measures and a page layout.

> A `.pbix` file is a binary Power BI Desktop artefact, so it is not generated by the Python pipeline.
> Follow the steps below to build it; the charts in `reports/figures/` show the expected result.

## 1. Load the data

*Get Data -> Text/CSV*, then load:

| File | Table role |
|------|-----------|
| `fact_opportunities.csv` | Fact (one row per deal) |
| `fact_targets.csv` | Fact (monthly revenue target) |
| `dim_accounts.csv`, `dim_sales_reps.csv`, `dim_products.csv`, `dim_date.csv` | Dimensions |
| `reports/forecast_next_quarter.csv`, `reports/forecast_backtest_predictions.csv` | Forecast tables (standalone) |

Set data types in Power Query: dates as **Date**, and `is_open`, `is_won`, `is_lost`, `in_active_pipeline`,
`dq_stale`, `dq_overdue` as **True/False**.

## 2. Relationships (Model view)

| From (many) | To (one) | Active? |
|-------------|----------|---------|
| `fact_opportunities[account_id]` | `dim_accounts[account_id]` | Yes |
| `fact_opportunities[owner_id]` | `dim_sales_reps[rep_id]` | Yes |
| `fact_opportunities[product]` | `dim_products[product]` | Yes |
| `fact_opportunities[close_date]` | `dim_date[date]` | Yes |
| `fact_opportunities[created_date]` | `dim_date[date]` | No (use `USERELATIONSHIP` when needed) |
| `fact_targets[month]` | `dim_date[date]` | Yes (targets sit on the 1st of each month) |

## 3. DAX measures

```DAX
Won Revenue = CALCULATE ( SUM ( fact_opportunities[amount] ), fact_opportunities[is_won] = TRUE () )

Won Deals = CALCULATE ( COUNTROWS ( fact_opportunities ), fact_opportunities[is_won] = TRUE () )

Closed Deals =
CALCULATE ( COUNTROWS ( fact_opportunities ),
    FILTER ( fact_opportunities, fact_opportunities[is_won] || fact_opportunities[is_lost] ) )

Win Rate = DIVIDE ( [Won Deals], [Closed Deals] )

Avg Sales Cycle (days) =
CALCULATE ( AVERAGE ( fact_opportunities[sales_cycle_days] ), fact_opportunities[is_won] = TRUE () )

Gross Margin % =
DIVIDE (
    CALCULATE ( SUM ( fact_opportunities[gross_margin_amount] ), fact_opportunities[is_won] = TRUE () ),
    [Won Revenue]
)

Revenue Target = SUM ( fact_targets[revenue_target] )

Revenue vs Target % = DIVIDE ( [Won Revenue], [Revenue Target] ) - 1

Open Pipeline = CALCULATE ( SUM ( fact_opportunities[amount] ), fact_opportunities[is_open] = TRUE () )

Weighted Active Pipeline =
CALCULATE ( SUM ( fact_opportunities[weighted_amount] ), fact_opportunities[in_active_pipeline] = TRUE () )

Stale or Overdue Pipeline =
CALCULATE ( SUM ( fact_opportunities[amount] ),
    FILTER ( fact_opportunities,
        fact_opportunities[is_open] && ( fact_opportunities[dq_stale] || fact_opportunities[dq_overdue] ) ) )

Pipeline At Risk % = DIVIDE ( [Stale or Overdue Pipeline], [Open Pipeline] )

Won Revenue PY = CALCULATE ( [Won Revenue], SAMEPERIODLASTYEAR ( dim_date[date] ) )
Won Revenue YoY % = DIVIDE ( [Won Revenue], [Won Revenue PY] ) - 1
```

## 4. Suggested pages

**Page 1 - Executive overview**
- KPI cards: Won Revenue, Revenue vs Target %, Win Rate, Avg Sales Cycle, Gross Margin %
- Clustered column + line: Won Revenue by `dim_date[month_start]` with Revenue Target as the line
- Bar: Won Revenue by `dim_accounts[industry]`
- Slicers: financial year (`fin_year_au`), team, product category

**Page 2 - Pipeline health**
- KPI cards: Open Pipeline, Weighted Active Pipeline, Pipeline At Risk %
- Stacked bar: Open Pipeline by stage, split by `dq_stale` / `dq_overdue`
- Table: top stale deals (account, owner, amount, days since last update) - the rep action list

**Page 3 - Forecast**
- Line + band from `forecast_next_quarter.csv` (statistical forecast, lower_80, upper_80)
- Clustered column: weighted pipeline vs forecast vs target by month
- Table from `forecast_backtest_predictions.csv` showing actual vs forecast per model

**Page 4 - Data quality**
- Bar chart from `reports/data_quality_audit.csv`; table of issues, severity and recommended fix

Tip: keep 4-5 KPIs per page, consistent colours, and a title that states the *takeaway*
(for example "Nearly a third of open pipeline is stale") rather than only the metric name.
